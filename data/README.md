# Data availability

The clinical chest CT data, annotations, patient-level labels, DICOM metadata, fold assignments, and derived CT volumes used for this thesis are not distributed with this repository.

Access to the original data is restricted. Researchers with appropriate authorisation must prepare their own local data directory and manifest following the schema in `example_manifest.csv`. The example rows are wholly synthetic and are provided only to document the expected fields.

Do not commit real patient identifiers, DICOM Series Instance UIDs, raw or derived image volumes, annotation spreadsheets, labels, or checkpoints to this repository.
